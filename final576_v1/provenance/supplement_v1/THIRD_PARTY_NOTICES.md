# Third-party provenance

The seven Verilog files in this dataset's `library/` are unchanged copies of
components included in MBD-Benchmark v1.0.0. They were generated using
[ArithsGen](https://github.com/ehw-fit/ariths-gen), revision
`2b5cc8f783b778043fdfca3d3f7e50a35cb69eaf` (version 1.1.4):

- UnsignedArrayMultiplier: 8, 16 and 32 input bits.
- UnsignedRippleCarryAdder: 8, 16, 32 and 64 input bits.

Module hashes are in `dataset_config.json`. No upstream Python source is
redistributed. New top-level compositions, sampling tools and observations were
created by the MBD-Benchmark project.

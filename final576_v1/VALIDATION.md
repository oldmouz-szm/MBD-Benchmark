# Frozen snapshot validation

The local selection passed byte-level copying and original-input rechecks,
the existing ArithDiag dataset discovery routine (576 entries), independent
metadata parsing, complete group/three-input checks, fault-site identity
within each group, fault-level and recipe coverage, and dataset checksums.
All integer and bit observations are unmodified copies of previously validated
source data. This release does not claim a new full gate-level replay of all
576 tasks, independent proof-certificate checking, or a uniform solver run.
The portable public verifier repeats integrity and structural checks only.
